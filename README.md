
# Pharmacy Management System using AI


This project is an AI-based Smart Pharmacy Management System designed to manage medicines, sales, and inventory efficiently. It also includes a basic AI chatbot to assist users with medicine availability and price information.


## Objectives

* To develop a basic pharmacy management system

* To manage medicine, stock, and sales records

* To use simple calculations for stock alerts and expiry tracking

* To design a chatbot assistant for user support



## Application Features

* User Sign Up

* User Sign In / Login

* User Logout

* Role-based access (Admin, Staff)

* Dashboard overview

* Add / Update / Delete medicines

* View & search medicines

* Inventory tracking

* Low stock alert

* Expiry alert

* Sales & billing

* Automatic stock update

* Sales history

* Chatbot assistant


## Tools & Technologies

* HTML, CSS
* Python 
* MySQL
* Rule-based AI & Chatbot
* VS Code

## Scope of the Project

* Suitable for small and medium pharmacies

* Can be extended with advanced AI features

* Helps improve efficiency and accuracy

## Expected Outcome

* Easy-to-use pharmacy system

* Faster access to information

* Better stock control 




## Conclusion

The Pharmacy Management System using AI provides an efficient and user-friendly solution for pharmacy operations. By integrating basic AI and a chatbot, it enhances automation and decision-making in pharmacy management.
